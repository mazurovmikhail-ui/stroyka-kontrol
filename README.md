# Контроль стройки

**→ https://mazurovmikhail-ui.github.io/stroyka-kontrol/**

Приложение для прораба: сроки, темп работ, фотожурнал и график поставок на объекте.
Открывается в браузере телефона, ставится на домашний экран, работает без интернета.
Данные лежат в памяти телефона и никуда не уходят.

Открыть на телефоне по адресу выше → меню браузера → «Установить приложение» или
«На главный экран». Дальше запускается с иконки и работает без связи.

## Что считает

**Прогноз срыва сроков.** По работе вносится накопленный объём на дату: было 88 м³,
стало 132 м³. Из последних четырёх замеров берётся темп в единицах в день, остаток
делится на темп — получается дата фактического окончания. Она сравнивается с планом:
разница и есть отставание. По объекту берётся самая поздняя из работ. Сигнал приходит
тогда, когда темп перестал вытягивать, а не в день сдачи.

**График поставок.** Расход материала в день = темп работы × норма расхода на единицу
объёма. Отсюда видно, на сколько дней хватит склада. Дата заказа = день, когда склад
кончится, минус срок поставки и запас прочности. Объём партии закрывает срок поставки
плюс горизонт, на который держим склад, минус остаток; больше, чем осталось по объёму
работы, приложение не закажет. Кратность партии округляет вверх.

**Фотожурнал.** Снимок привязывается к работе и дате, помечается как отклонение и
закрывается, когда устранено. Открытые отклонения висят на сводке. Фото сжимается
до 1400 px по длинной стороне и хранится в IndexedDB.

Пока факта по работе нет, расход считается по плановому темпу — в карточке материала
подписано, по какому. Если прироста за последние замеры нет, прогноз не выдумывается:
так и пишется, что считать не по чему.

## Разбор фото нейросетью

Единственная функция, которой нужен интернет и внешний сервис. По умолчанию выключена.
Чтобы включить: завести ключ на [openrouter.ai](https://openrouter.ai) (регистрация из
России работает, есть бесплатные модели) и вставить его в «Ещё → Разбор фото нейросетью».
Ключ хранится только на этом телефоне и подставляется в запрос прямо из браузера, поэтому
заводите ключ с лимитом расходов и не открывайте приложение на чужом устройстве.

DashScope от Alibaba для этого не подходит: консоль не открывается с зарубежных адресов,
а регистрация требует китайский номер и платёжку.

## Как запустить

**На компьютере.** Из папки приложения:

```bash
python -m http.server 8778
```

Дальше `http://localhost:8778`. Просто открыть `index.html` двойным щелчком не выйдет:
на схеме `file://` браузер запрещает IndexedDB, и фотографии не сохранятся.

**На телефоне.** Уже опубликовано на GitHub Pages из ветки `main`, папка `/`:
https://mazurovmikhail-ui.github.io/stroyka-kontrol/

Чтобы выкатить изменения — обычный `git push` в `main`, Pages пересоберётся сам за
минуту-две. Не забудьте поднять номер кэша в `sw.js` (см. ниже), иначе у тех, кто уже
открывал приложение, останется старая версия.

## Данные

Записи в `localStorage`, фотографии в `IndexedDB`. Всё привязано к конкретному браузеру
на конкретном телефоне: очистка данных сайта или переустановка браузера сотрёт записи,
синхронизации между устройствами нет.

«Ещё → Выгрузить данные в файл» сохраняет объекты, работы, замеры и материалы в JSON.
Фотографии в выгрузку не входят — они тяжёлые. Раз в неделю выгружайте.

## Файлы

```
index.html              каркас страницы
styles.css              оформление
app.js                  всё остальное: хранилище, расчёты, экраны
sw.js                   офлайн-кэш (сеть вперёд, кэш как подстраховка)
manifest.webmanifest    описание для установки на домашний экран
icon.svg                иконка
```

Расчёты живут в `app.js` в разделе 4: `workStats` — темп и прогноз по работе,
`projectStats` — по объекту, `supplyStats` — заказ материала. Остальной код только
рисует то, что они вернули.

При выкладке обновлённой версии поднимите номер в `const CACHE = 'stroyka-v1'` в
`sw.js`, иначе у тех, кто уже открывал приложение, может остаться старый кэш.
